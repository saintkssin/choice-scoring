# choice-scoring

Автоматичний скоринг дзвінків сейлсів по скрипту продажів. Завантажує записи з Ringostat, транскрибує і оцінює через Gemini 2.5 Flash, генерує CSV та текстовий звіт.

## Яку проблему вирішує

Ручна перевірка якості дзвінків менеджерів займає 30+ хвилин на людину щотижня. Потрібна автоматична оцінка по конкретному скрипту продажів.

Стандартний стек (ChatGPT + Whisper) коштував би ~$150/міс. Цей pipeline обходиться ~$0.40 за 15 дзвінків — Gemini 2.5 Flash підтримує аудіо нативно, окремий STT-сервіс не потрібен.

## Як працює

Pipeline з 4 кроків, запускається однією командою:

1. **`1_fetch_calls.py`** — тягне вихідні дзвінки з Ringostat API за останні 14 днів, фільтрує по менеджерах і мінімальній тривалості (≥ 60 сек)
2. **`2_transcribe.py`** — транскрибує аудіофайли через Gemini 2.5 Flash
3. **`3_score.py`** — оцінює кожен транскрипт по 6 блоках скрипту (`script.json`). Результат — JSON з оцінкою 0–10 і цитатою для кожного блоку
4. **`4_report.py`** — збирає всі оцінки в `output/report.csv` та `output/report_detailed.txt`

Повторний запуск пропускає вже оброблені файли.

## Стек

- Python 3
- [google-genai](https://pypi.org/project/google-genai/) — Gemini 2.5 Flash
- Ringostat API

## Конфігурація (`config.py`)

| Параметр | Опис |
|---|---|
| `RINGOSTAT_API_KEY` | API ключ від Ringostat |
| `GEMINI_API_KEY` | API ключ від Google AI Studio |
| `MIN_DURATION` | Мінімальна тривалість дзвінка в секундах (за замовчуванням 60) |
| `MANAGERS` | Список прізвищ менеджерів для фільтрації. Порожній список = всі вихідні |

## Блоки скрипту (`script.json`)

| # | Блок |
|---|------|
| 1 | Аналіз клієнта перед дзвінком |
| 2 | Встановлення контакту |
| 3 | Виявлення потреби |
| 4 | Презентація |
| 5 | Робота із запереченнями |
| 6 | Закриття |

## Запуск

```bash
pip install requests google-genai
# вставити RINGOSTAT_API_KEY та GEMINI_API_KEY в config.py
python3 run.py
```

**Результати:** `output/report.csv` · `output/report_detailed.txt` · `output/scores/<call_id>.json`

## Обмеження

- Ringostat API не підтримує фільтр по типу дзвінка через `filters` — фільтрація вихідних реалізована в коді по полю `caller`
- Точність розподілу спікерів ([МЕНЕДЖЕР] / [КЛІЄНТ]) залежить від якості аудіо
